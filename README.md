# Checkstride for Jira — Support

Welcome to the official Checkstride support portal, maintained by FerrySwiss.

## Report a problem or request a feature

Open the Issues tab and click New issue.

Please include:
- A description of your problem or request
- Steps to reproduce the problem
- Expected and actual behaviour
- Screenshots with sensitive information removed

GitHub issues are public. For confidential support or security concerns,
email info@ferryswiss.com.
